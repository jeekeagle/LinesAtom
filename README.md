# 讲义轴 · 结构化讲稿系统

为一份讲稿建立一条确定性时间轴，并在时间轴的指定位置挂载对应的学习介质，使同一条讲稿能够承载多层次的认知支持。

系统分两层：**介质引擎**负责生成一切内容（概念、标注、挂载建议、介质），**技能台**负责约束它怎么生成（可停用、可改参数、可改提示词）。

## 快速开始

```bash
npm install          # 首次需要（依赖已随包准备好时可跳过）
npm run build        # 构建前端
npm start            # 启动服务，默认 http://127.0.0.1:8790
```

开发模式（前端热更新 + 后端自动重启）：

```bash
npm run dev
```

打开 `http://127.0.0.1:8790` 后：

| 页面 | 作用 |
| --- | --- |
| 课程台 | 课程 → 章节 → 微课单元的开发、章节管理与发布 |
| 总览 | 讲稿概况、四项首版验收、流水线状态 |
| 剪辑台 | 剪映式时间线；逐行挂载建议，可一键确认 / 修改 / 拒绝 |
| 阅读台 | 连续长文阅读；挂载内容就近展开，关闭后精确回到原位 |
| 结构台 | 概念表、标签分布、挂载指针表 |
| 流程台 | 三种生产模式与阶段契约 |
| 技能台 | 技能台账：停用、改参数、改提示词、单独试运行 |
| 介质引擎 | 介质引擎编排与四段流水线运行 |
| 设置台 | 二级菜单：模型服务 / 声音服务 / 语音识别 / 流水线参数 / 数据与系统 |

右上角的**端切换**在创作端与学生端之间切换：发布之后，学生端才看得到课程。

## 学生端

| 页面 | 作用 |
| --- | --- |
| 课程列表 | 只列已发布课程与总时长 |
| 课程页 | 慕课式结构：章节 → 单元，带进度与「继续学习」 |
| 单元页 | 顶部 16:9 网页视频：播放键、TTS 讲解、课件随讲稿逐块切换；下方**素材窗口**有三条线（当前挂载 / 关联概念 / 同章素材）持续推送材料，任意一张都能点开反复查看 |

发布即冻结快照：发布后继续改稿只影响创作端，学生端仍看已发布版本。

## 声音与识别（MiMo）

- **声音服务**：按句调用 MiMo TTS（`mimo-v2.5-tts`），旁白随字幕推进；播放条里可切换「本地语音 / 远端音色」，下一句自动预取。
- **语音识别**：`mimo-v2.5-asr`，测速时先用声音服务合成一句再转写，可直接看到转写结果与耗时。
- **服务档案**：模型 / 声音 / 识别各自可新建、编辑、切换默认、测速与删除；每个档案的 API Key 独立保存在 `data/secrets.json`，不进代码、不随导出外发。
- 密钥与模型清单：`GET /api/services`、`POST /api/audio/tts`、`POST /api/audio/asr` 由服务端代理，浏览器不持有密钥。

## 数据要点

- `pointers` 只存目标编号，介质正文独立存放在 `media` 与 `concepts`，内容可跨课复用。
- 标注与讲稿同批产出，块编号是唯一纽带；改稿后在介质引擎执行「重算标注与挂载」即可同步。
- 回指位置只存跳转，不重复挂载。
- API Key 单独存放在 `data/secrets.json`，不随导出与备份外发。

详见 `docs/01-quick-start.md` 与 `docs/05-data-model.md`。
