# 快速开始

## 准备

- Node.js 20 或更高版本。
- 首次运行需要安装依赖：`npm install`。
- 不需要模型服务也能完整使用：未配置模型时，全部流水线由本地确定性引擎完成。

## 启动

```bash
npm run build
npm start
```

浏览器访问 `http://127.0.0.1:8790`。开发模式用 `npm run dev`（前端 5173，自动代理到 8790）。

## 三条最短路径

1. **读一遍**——进「阅读台」，点开任意挂载点，看支架内容，关闭后阅读位置会精确回到原处。
2. **改一遍挂载**——进「剪辑台」，点「重新生成建议」，逐行得到 Agent 的挂载建议，可单条确认、修改介质类型与目标、或拒绝；「一键确认」按置信度门槛批量确认。
3. **重做一遍讲稿**——进「引擎台」，粘贴讲稿素材与骨架概念，运行流水线，得到新的块、标注与挂载，再回剪辑台复核。

## 环境自检

```bash
node cli/lecture-axis.mjs doctor
```

检查 Node 版本、数据目录可写性与服务在线状态。
