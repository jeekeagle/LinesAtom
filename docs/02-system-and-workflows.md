# 系统与流程

## 分层

```text
界面层    剪辑台 · 阅读台 · 结构台 · 技能台 · 引擎台
编排层    引擎（阶段 + 技能组合） · 流程（模式 + 步骤）
生成层    技能（提示词 + 参数 + 开关） · 模型适配
数据层    概念条目 · 讲稿块 · 挂载指针 · 介质内容 · 挂载建议
```

四层之间只通过结构化数据通信。界面不直接产出数据，数据不感知界面。

## 四段流水线

| 段 | 输入 | 输出 | 判定 |
| --- | --- | --- | --- |
| 内容基座构建 | 主题、思路、素材、骨架概念 | 概念表、关系网、素材池 | 每个概念有定义与上位类；关系网无孤立节点 |
| 讲稿生成与同步标注 | 基座、时长、认知负荷上限 | 正文、块切分表、标签表 | 总字数符合时长倒推；核心概念不超上限；无未标注块 |
| 挂载编排 | 标注表、基座 | 挂载指针表、待生成介质清单 | 每个核心概念锚点有卡片；无重复挂载；回指仅存跳转 |
| 呈现渲染 | 讲稿、标注、挂载、介质 | 单页网页 | 跳转即时，上下文连续，返回原位不丢进度 |

引擎台把这四段拆成六个可观测步骤：内容基座构建 → 讲稿切分 → 同步标注 → 介质生成 → 挂载编排 → 验收分析。每一步都在运行抽屉里留痕。

## 三种生产模式

| 模式 | 适用 | 路径 |
| --- | --- | --- |
| 讲稿驱动 | 有主题与素材，希望系统推进到底 | 素材 → 基座 → 切分 → 标注 → 介质 → 挂载 → 验收 |
| 素材驱动 | 已有成稿，希望系统按语义边界归位 | 成稿归位 → 基座 → 切分 → 标注 → 介质 → 挂载 → 验收 |
| 骨架驱动 | 已有概念清单，希望围绕骨架组织讲稿 | 骨架装载 → 基座 → 切分 → 标注 → 介质 → 挂载 → 验收 |

模式只改变起点与顺序，不改变数据契约。流程可在流程台启用、停用与切换默认。

## 剪辑台的三条轨道

- **文稿轨**：讲稿块按时长排布，左侧色条即六类标签。
- **挂载轨**：已经落地的介质，标明介质类型。
- **建议轨**：Agent 给出的逐行挂载建议，状态分待确认、已确认、已拒绝、已修改。

播放头跟随时间轴移动，预览区同步显示当前行与它的介质内容。空格播放、左右方向键换行、点击时间尺定位、拖动滑块缩放。
