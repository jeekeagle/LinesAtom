# 介质引擎与技能

## 引擎

引擎按阶段编排技能。同一阶段可以有多个引擎，但只有一个默认引擎。

| 阶段 | 引擎 | 技能 |
| --- | --- | --- |
| 析课 | 内容基座分析引擎 | concept-extract |
| 讲稿 | 讲稿切分与标注引擎 | block-label、concept-extract |
| 挂载 | 挂载编排引擎、挂载顾问 | mount-planner、mount-advisor |
| 介质 | 概念卡 / 案例 / 问答 / 速查表 / 课件页 / 章节导图引擎 | 对应六个介质技能 |
| 验收 | 验收分析引擎 | validation |

## 技能

技能是引擎背后的真正产出者：一个技能 = 提示词 + 参数 + 开关 + 版本。

- 在技能台可以停用技能、改参数、改提示词、单独试运行。
- 停用介质技能会立刻改变产物：案例技能停用后，理解性例子不再挂案例，验收会体现差别。
- 停用分析技能会让标签退化为默认衔接，验收的「标注完整性」仍成立但「概念卡覆盖」会失败——这是设计意图：让依赖关系可见。

## 模型接入

模型服务可选。配置方式：设置台填服务地址、模型名称与 API Key，密钥写入 `data/secrets.json`。

- 未配置或调用失败时，流水线自动回落到本地确定性算法，产物结构完全一致。
- 提示词里的 JSON 契约约束模型输出；解析失败同样回落。
- 挂载顾问技能默认使用本地规则（`useModel: false`），需要模型逐行给建议时可在技能参数里打开。

## 逐行挂载建议

讲稿定稿后，挂载顾问逐行给出建议：挂什么、挂到哪里、为什么、把握多大。

- 「一键确认」按置信度门槛（默认 0.6）批量确认，低置信建议（例如过渡行）保留待定，避免误挂。
- 「修改」可以换介质类型、换挂载目标、改写理由，保存即写入真实挂载指针。
- 「拒绝」保留痕迹，方便回看当时为什么没挂。
