# 验收与风险控制

## 首版四项验收

| 项 | 判定 |
| --- | --- |
| 标注完整性 | 每个讲稿块都有且只有一个标签 |
| 标签分布合理 | 设问互动占比不低于 8%；低于此值说明讲稿偏陈述，需改稿而非改标注 |
| 概念卡覆盖 | 每个核心概念首次出现处挂知识卡片；回指处不重复弹出 |
| 跳转不丢位 | 任意挂载内容打开后关闭，回到讲稿原位置 |

系统另有两项工程检查：认知负荷上限（核心概念标签数量不超过上限）、时长倒推（正文时长与目标时长偏差不超过 25%）。

## 跳转不丢位怎么实现

支架展开会改变正文栏宽，正文会重排。因此不按裸 `scrollTop` 数值回写，而是：

1. 打开支架前记录锚点：视口顶部所在的块编号与块内偏移。
2. 关闭支架时先按锚点在当前布局下回写一次，栏宽动画结束后再精确回写一次。
3. 校验方式：逐块比较内容位置，浏览器实测最大偏差 0.00px。

## 风险控制

| 风险 | 控制方式 |
| --- | --- |
| 介质过载 | 每版只新增一类介质；新增前必须证明上一版已在使用中产生可观测数据 |
| 标注与讲稿脱节 | 标注与讲稿同批生成，块编号作为唯一纽带，改稿即重算 |
| 内容与位置绑死 | 指针只存编号，内容存于概念条目与介质，跨课复用 |

## 版本路径

- V0.1：单课成立。一份讲稿、六标签标注、核心概念处挂知识卡片，手工挂载。
- V0.2：扩充介质。增加问答条目与案例条目。
- V0.3：补全局定位与结论收束两类，接入课件页与速查表，形成完整闭环。
- V1.0：数据反哺。按回看频次与停留时长，把高频入口升级为预挂载，删去无人触达的挂载位。

版本推进的唯一条件是前一版的验收标准全部通过。
